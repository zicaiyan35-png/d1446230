# 大二影展專題：《舊市尋味》網頁專案

本專案為逢甲大學大二行銷影展專題網頁，由甲九團隊製作，主題聚焦於臺中市中區百年歷史的「臺中第二市場」。透過「舊市尋味」的核心概念，打破年輕族群長久以來對傳統市場「老舊、買菜專屬、與年輕人有距離」的刻板印象，引導大學生與年輕族群從「居住在臺中卻對在地文化陌生」轉為主動探索，走入市場品嚐在地古早味小吃、認識六角樓歷史建築，看見舊城區的生活溫度與文化脈絡。

---

## 專案功能與技術特色

* **SEO 最佳化**：包含完整的 Meta 標籤、Open Graph 社交分享協議與語意化 HTML5 標記（`<header>`, `<main>`, `<article>`, `<aside>`, `<time>`）。
* **RWD 響應式佈局**：支援手機、平板與桌上型電腦，影片區塊具備 16:9 自適應縮放，行動裝置螢幕下自動切換為單欄堆疊模式。
* **CSS Grid & Flexbox 系統**：使用 CSS Grid 實作雙欄側邊導覽列（`sticky` 效果）與主要內容區塊，搭配自訂 CSS 變數（紅磚色 `#9e2a2b` 與米色 `#f4ece6`）呈現文青復古質感。
* **檔案模組化切割**：HTML 檔案結構乾淨，樣式獨立抽離至 `css/5.css`，方便進行後續維護與擴充。

## Vibe Coding 指令紀錄 (Prompts Log)

本專案採用 Vibe Coding 人機協同開發模式，透過明確的視覺風格、頁面架構與 RWD 規範進行網站建置。以下為開發過程的核心 Prompt：

### Prompt 1：專案架構與語意化骨幹建立
> **Prompt:**  
> 「請扮演資深前端工程師與數位行銷策展人。我正在製作大二影展專題介紹網頁，主題是針對臺中第二市場翻轉刻板印象的短片企劃《舊市尋味》（核心精神：『走入第二市場，感受台中日常』）。  
> 請幫我建立一個結構完整、採用 HTML5 語意化標籤（`<header>`, `<nav>`, `<aside>`, `<article>`, `<section>`, `<time>`）的單頁式現代化靜態網站。  
> 規範要求：  
> 1. 具備全域頂端導覽列與側邊快速導覽選單（含快速錨點跳轉）。  
> 2. 具有完整的 SEO Meta 標籤（含 Title, Description, Author, Open Graph）。  
> 3. 將 CSS 樣式獨立抽離至 `css/5.css` 檔案。  
> 4. 網頁建置者標示為『蔡芷妍』，內容涵蓋專案概述、STP 定位、競爭者比較表與預期效益。」

### Prompt 2：CSS Grid 雙欄佈局與復古色調定型
> **Prompt:**  
> 「請為《舊市尋味》專題網頁撰寫完整的 `css/5.css` 樣式表，要求如下：  
> 1. 使用 CSS 變數（`:root`）定義飽滿紅磚色（`#9e2a2b`）、溫潤米色（`#f4ece6`）與暖橘色（`#e09f3e`），營造貼合舊城文化與古著復古氛圍的質感。  
> 2. 版面採用 CSS Grid 雙欄結構（左側 280px `sticky` 側邊欄 + 右側主內容區），設定平滑滾動效果（`scroll-behavior: smooth`）。  
> 3. 加入對競爭者分析表（`info-table`）與重點標示（`mark` / `.reading-focus`）的精細處理。  
> 4. 使用 `@media (max-width: 900px)` 斷點設定 RWD 響應式，行動裝置上自動轉為單欄，並展開內文原有的專題目錄。」

### Prompt 3：行銷企劃內容整合與細節修修
> **Prompt:**  
> 「請將《甲九－舊市尋味》企劃書內容填入 HTML 結構中：  
> 1. 加入目標客群洞察（18–24歲在臺中生活但對傳統市場陌生的年輕族群，痛點：『我不是不想認識臺中，而是不知道要從哪裡開始』）。  
> 2. 整理第二市場與第四市場、一中商圈、大型量販店之 4Ps 競爭者評估表格。  
> 3. 嵌入帶路探店的故事化腳本與 Slogan：『走入第二市場，感受台中日常。』  
> 4. 頁尾與側邊欄需清楚標註專題組別『甲九』、指導老師群與全體組員分工。」
